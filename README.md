# 战争雷霆 · 语音包提取器 (War Thunder Voice Extractor)

一款从《战争雷霆》(War Thunder) 游戏语音包 (`.bank`) 中提取各国车组喊话的 Windows 小工具。

自动检测游戏语音目录 → 选择国家 → 一键提取全岗位喊话（车长/驾驶员/炮手/装填手/火炮支援），自动翻译成中文文件名，内置试听。

## ✨ 功能

- 🎮 **自动检测游戏目录**：无需手动找路径，自动定位 `War Thunder\sound` 文件夹
- 🌍 **35 种语言包**：德国、苏联、美国、英国、日本、中国、法国、意大利…全科技树语言
- 🎙️ **第二套配音 (sm_)**：部分语言提供第二套独立配音，下拉里单独标注
- 📝 **中文文件名**：`voice_message_commander_shot_v1.ogg` → `车长_开火_v1.ogg`
- ▶️ **内置试听**：提取完直接播放，双击列表项也行
- 🌙 **纯黑界面**：黑底白字，深夜打游戏也不刺眼

## 📋 系统要求

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 / 11 |
| 运行时 | [Node.js](https://nodejs.org)（提取引擎依赖，装 LTS 版即可） |

## 🚀 使用

1. 下载后解压，双击 **`战争雷霆语音包提取器.exe`**
2. 顶部选择国家（默认自动检测游戏目录；检测不到可点"手动选文件夹"）
3. 设置输出目录（默认 `D:\HermesData\wt_voices_de`）
4. 点击 **开始提取**，等待进度条跑完
5. 完成后在列表里试听，或点"打开输出文件夹"

> 💡 提取一次大约 3~10 秒，取决于语音包大小（约 1000~1500 条语音）。

- 语音包位置：`<游戏目录>\sound\_crew_dialogs_ground_<语言>.assets.bank`
- 语言代码对照：`de`=德国、`ru`=苏联、`en_us`=美国、`jp`=日本、`zh`=中国…
